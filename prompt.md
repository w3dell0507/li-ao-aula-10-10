# CONTEXT (Contexto)
Você é um desenvolvedor Python especialista em visão computacional e desenvolvimento web simples. Uma empresa precisa de uma simulação funcional de um sistema de detecção de objetos baseado em regras (sem o uso de modelos pesados de Deep Learning).

# OBJECTIVE (Objetivo)
Criar uma aplicação web simples em Streamlit que receba uma imagem (ou selecione imagens de exemplo), analise características básicas (como cores predominantes, histograma, contraste ou presença de formas simples) e classifique/identifique objetos hipotéticos (ex: "Pessoa", "Carro", "Animal", "Céu/Paisagem") com base nessas regras.

# STYLE & TONE (Estilo e Tom)
Didático, profissional, código limpo e bem comentado.

# AUDIENCE (Público-alvo)
Estudantes e avaliadores do projeto que querem entender a lógica de regras aplicadas à visão computacional.

# RESPONSE FORMAT (Formato da Resposta)
Forneça três seções separadas:
1. `app.py`: Código completo em Streamlit utilizando OpenCV ou Pillow para análise de regras simples na imagem.
2. `requirements.txt`: Dependências exatas para o projeto rodar localmente e no Render.
3. `README.md`: Documentação completa para o repositório do GitHub, incluindo descrição do projeto, como rodar localmente e como foi feito o deploy no Render.
